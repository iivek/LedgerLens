# Dataset licenses & attribution

This project trains on third-party datasets. Their terms are independent of this
repo's Apache-2.0 code license and apply to the data (and to any model weights
derived from it) regardless of how the code is licensed.

## CORD-v2

- **Source:** [naver-clova-ix/cord-v2](https://huggingface.co/datasets/naver-clova-ix/cord-v2) (NAVER CLOVA), from Park et al., *CORD: A Consolidated Receipt Dataset for Post-OCR Parsing*.
- **License:** CC BY 4.0, confirmed on both the [Hugging Face dataset card](https://huggingface.co/datasets/naver-clova-ix/cord-v2) and the [original clovaai/cord repository](https://github.com/clovaai/cord).
- **Obligation:** attribution to NAVER CLOVA / the CORD authors when the dataset or derived weights are distributed.

## SROIE (ICDAR 2019 Robust Reading Challenge, Task 3)

- **Source used in this repo:** the [`urbikn/sroie-datasetv2`](https://www.kaggle.com/datasets/urbikn/sroie-datasetv2) Kaggle mirror (`data/raw/SROIE2019/`), a third-party re-upload of the ICDAR 2019 competition data hosted at [rrc.cvc.uab.es/?ch=13](https://rrc.cvc.uab.es/?ch=13).
- **License: unconfirmed — treat as research-use only.** The competition's own terms page could not be verified (TLS error on the CVC host at the time of writing), and the Kaggle mirror does not display an explicit license. A commonly cited MIT license on an adjacent GitHub download-script repo (`zzzDavid/ICDAR-2019-SROIE`) covers only that repo's *code*, not the dataset — do not cite it as the dataset's license.
- **Action before any use beyond this repo's internal research/eval purposes** (redistribution, commercial use, publishing derived weights trained on SROIE beyond a research model card): contact the RRC/ICDAR organizers or re-verify terms directly at the source above.

## Synthetic invoices (`data/synthetic/`)

Generated by this repo (`src/ledgerlens/data/synthetic/`) — no external license constraints. Faker-generated names/addresses/companies are synthetic, not real entities.

## Personal holdout (`data/personal_holdout/`, if/when added)

Photographed by the project author. Exclude from any public release if it contains privacy-sensitive information (spec §4).

## Model weights trained on this data

Any checkpoint (teacher-distilled, quantized, or pruned) trained on CORD and/or SROIE inherits the obligations above. Model cards published to Hugging Face must name both datasets and link this file.
